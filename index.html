Serve this directory over HTTP (e.g. npx serve or python3 -m http.server) — module scripts and fetch do not run from file://. The burn scar's narrow finger points north; if it points down, the orientation rule is broken (README “Raster orientation”). URL switches: ?fallback=1 forces the CPU painter, ?gradient=1 loads the published-gradient variant, ?t=0.75 opens paused at a scrub position, ?end=perimeter preselects an end-frame style.
